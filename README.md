# Jaman Portfolio

Complete editable source of the published portfolio, including the animated cursor and LinkedIn links.

## Run
Extract the ZIP and open index.html in a browser. No npm install or build step is required.
You can also open this folder in VS Code and use Live Server.

## Edit
- index.html: profile, experience, projects, skills, and social links
- style.css: colors, typography, spacing, responsive layout, and cursor appearance
- app.js: background network animation and cursor behavior
- favicon.svg: browser tab icon

Google Fonts requires an internet connection; system fonts are used as a fallback.
The cursor ring is enabled on mouse devices with reduced motion turned off.

## Host elsewhere
Upload index.html, style.css, app.js, and favicon.svg together to any static web host.
Keep all four files in the same directory. No server-side code or environment variables are needed.
